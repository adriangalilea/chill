### Added

- **chill tells you when a new version is out.** Once a day the app asks chill.untitled.garden which version is the newest, and when yours is older the menu says so: a press copies the brew command that upgrades it, or opens the download page if chill came from the dmg.

### Changed

- **chill now makes one request a day, and you can turn it off.** It carries a random code chill made the first time it checked, tied to nothing about you or your Mac, so the studio can count how many copies are in use; no IP address, no name, no hardware is kept. "Check for updates daily" in the menu turns it off. The fan daemon still never touches the network.
